# Seguimiento ERLA de Salida 2026

Tablero de seguimiento de participación en la evaluación ERLA de Salida 2026 de Lima Metropolitana.

## Publicación en GitHub Pages

1. Crear repositorio público `seguimiento-erla-salida-2026`.
2. Subir `index.html` a la raíz del repositorio.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Abrir `https://TU-USUARIO.github.io/seguimiento-erla-salida-2026/`.

**Corte:** 04/11/2026 - 16:20 hrs. Los datos incluidos están agregados por institución y características educativas; no se incluye el código individual de estudiante.
